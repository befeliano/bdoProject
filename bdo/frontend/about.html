Proje Hakkında

Sistem Mimarisi

BDO Proje, şehir planlamacıları ve trafik mühendisleri için tasarlanmış, çok katmanlı bir AI optimizasyon altyapısıdır.

01 Üretim Motoru — C++ L-Sistemi

Lindenmayer sistemleri (L-sistemleri), biyolojik büyüme modellerinden ilham alır. Projemizde bu formalizm, şehir yol ağlarının üretiminde kullanılır. Her iterasyonda üretim kuralları uygulanarak fraktal yapılar elde edilir.

C++17 L-SYSTEM FRAKTAL CFG
02 Veri Ayrıştırma — TOON Format

C++ motorundan çıkan ham string verisi, özel Python parser'ımız aracılığıyla TOON (Traffic Object Notation) formatına dönüştürülür. Bu adımda halüsinasyon filtreleri, geometrik tutarsızlıkları ve izole düğümleri eler.

PYTHON TOON REGEX GRAPH
03 AI Analiz — Gemini LLM

Yapılandırılmış TOON verisi, Gemini LLM'e gönderilir. Model, tıkanıklık noktalarını (yüksek derece kavşaklar), çıkmaz sokakları ve izole bölgeleri tespit eder; ardından mantıksal bypass rotaları önerir.

GEMINI PROMPT ENG. JSON MODE
04 Doğrulama — SUMO Simülatörü

LLM önerileri uygulandıktan sonra, nihai ağ .net.xml formatına çevrilerek Eclipse SUMO trafik simülatörüne aktarılır. Simülasyon sonuçları, optimizasyonun etkinliğini kanıtlar veya red eder.
